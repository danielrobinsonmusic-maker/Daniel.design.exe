# Daniel.design.exe

A Phaser-based web project built with Vite.

## Overview

This project uses Phaser for game scenes and Vite for fast development.

## Setup

Install dependencies:

```bash
npm install
```

## Run locally

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in the terminal (for example `http://localhost:5177/`).

## Project structure

- `src/main.js` — game entrypoint
- `src/game.js` — game configuration
- `src/scenes/` — Phaser scenes
- `index.html` — Vite HTML entry
