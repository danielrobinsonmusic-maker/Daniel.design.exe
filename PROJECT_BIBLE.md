# Daniel.design.exe

## Vision

Daniel.design.exe is an interactive portfolio presented as a small pixel-art town.

The experience should feel calm, approachable, and polished—not like a game that forces visitors to complete objectives. Visitors can immediately access professional content or wander through the town at their own pace.

The project should showcase design thinking through the experience itself.

---

# Core Principles

1. Resume first.
2. Exploration is optional.
3. No unnecessary complexity.
4. Simple code is preferred over clever code.
5. Every milestone should leave the project in a working state.

---
